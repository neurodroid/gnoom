## Current hardware

- **Optoma ZH507+ projector.** Laser DLP, native 1,920 × 1,080 at 16:9, 1.40:1 to 2.24:1 throw ratio, 100% native offset, and +16% vertical lens shift. The starting warp uses the 1.40:1 wide end of the zoom. [Product information and downloads](https://www.optomausa.com/product/zh507plus) · [Datasheet](https://www.optomaeurope.com/ContentStorage/Documents/5e0f7680-b3c2-4757-b209-eaa4bd604dac.pdf) · [Mounting drawing](https://region-resource.optoma.com/products/import/Documents/68c3ecca-dc75-4dcb-bd37-7dae9384251e.PDF)
- **Seton JB DDOME4 mirror.** The 500 mm half-dome model has a 510 × 245 mm exterior in the manufacturer's drawing. [Seton technical sheet](DMEU_TDS_Y4261312_FR_std.lang.all.pdf) · [Product information](https://www.seton.fr/miroirs-surveillance-interieurs-demi-dome.html#JB%20DDOME4)
